⚙️ Proxy de flux

Le proxy contourne deux blocages du navigateur : les flux en http:// non sécurisé et les serveurs sans CORS. Le flux vidéo transite alors par le proxy.

Un proxy Cloudflare Worker personnel est déjà configuré par défaut (rapide, non partagé). Pour en utiliser un autre, colle son URL ici (le fichier proxy-worker.js du repo permet d’en déployer un en 5 min — voir TESTING.md). Note : les chaînes géo-bloquées ou mortes resteront illisibles quel que soit le proxy ; le bouton VLC reste la valeur sûre.
