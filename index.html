    ⚙️ Proxy de flux

    Le proxy contourne deux blocages du navigateur : les flux en http:// non sécurisé et les serveurs sans CORS. Le flux vidéo transite alors par le proxy.

    Les proxys publics dépannent mais sont lents et limités. Pour un résultat fiable, déploie ton propre proxy (gratuit, 5 min) avec le fichier proxy-worker.js du repo — instructions dans TESTING.md — puis colle son URL ici. Note : les chaînes géo-bloquées ou mortes resteront illisibles quel que soit le proxy ; le bouton VLC reste la valeur sûre.
